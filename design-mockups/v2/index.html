计划页布局 v2

同一套纸感风格（晨间/日间/夜间 + 进度环），按你的意见统一改成：添加按钮 + 弹窗（弹窗里可选「日任务 / 周目标」）、已完成和夜间复盘都是按钮弹出页面、周目标由子任务全完成才算完成。三套只是主布局不同。

布局 1

三段式工作台

晨间看本周方向、日间执行今日任务、夜间复盘按钮。完整复刻"先想后做、晚上复盘"的一天。

打开预览 → 布局 2

双栏工作台

今日任务占主屏，本周方向常驻右侧窄栏。适合每天打开只看"今天"，方向瞄一眼即可。

打开预览 → 布局 3

标签页工作台

今日 / 本周方向 / 已完成 / 复盘四个页签，全部按钮驱动，每个页面只干一件事。

打开预览 →

提示：三套稿内部都可点——勾选子任务/任务会联动进度环和本周完成度；「添加」弹窗里切「周目标」可加新方向；已完成页可点开详情并"重新打开"；复盘页可逐项或全部顺延。周历版（旧方案 C）按你的意见已弃用。
